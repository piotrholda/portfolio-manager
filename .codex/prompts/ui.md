# Dodanie warstwy webowej do projektu

- UI powinien umożliwiać wywoływanie istniejących endpointów API oraz oglądanie wyników w formie tabel oraz wykresów.
- Na początku zaproponuj architekturę i technologię wykonania. Preferowany przeze mnie jest React. Dobrze byłoby to rozwijać nadal w tym samym repozytorium kodu.
- Przechowuj stan sesji w pliku markdown żeby można było wrócić do przerwanej pracyw kolejnych sesjach.
